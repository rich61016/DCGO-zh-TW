DCGO 繁體中文化 — 遊戲版本 1.19.0，含自動更新（Windows／macOS）

所有修改都只在這個資料夾裡。

■ 怎麼啟動（重要，2026-10-14 起改用這個）
雙擊本資料夾裡的「啟動DCGO（自動更新）.command」。它會：
  1. 向官方更新伺服器（與官方啟動器相同：dcgo.online）檢查有沒有新版本；
  2. 有新版就只下載有變動的檔案，每個檔案都驗證雜湊；
  3. 自動重新套用繁體中文化並做完整驗證；
  4. 用 Cyder 開啟遊戲。
  沒有新版本時會直接開遊戲；沒有網路時也會用目前的版本開遊戲。
  第一次雙擊如果 macOS 問要不要開啟，選「打開」即可（會開一個「終端機」視窗顯示進度）。
- 也可以照舊用 Cyder 直接開啟 Game\DCGO.exe，只是這樣不會檢查更新。
- 不要使用官方啟動器（DCGO_Launcher.exe.請勿使用）。它會把中文化的檔案「修復」成英文原版。

■ 在 Windows 上使用
1. 先安裝 Python 3.13（https://www.python.org/downloads/windows/ ，安裝時勾選「Add python.exe to PATH」）。
   不要用最新的 3.15（太新，需要的套件還沒有支援）。沒有裝也沒關係，啟動檔會詢問是否自動安裝 3.13。
2. 取得工具：從 GitHub 下載公開儲存庫 rich61016/DCGO-zh-TW（git clone 或下載 ZIP 後解壓縮）。
3. 雙擊「啟動DCGO（自動更新）.bat」。第一次會建立 Python 環境、從官方伺服器下載完整遊戲（約 700 MB）、
   用 Windows 內建的「微軟正黑體」產生中文版，然後直接開啟遊戲（Windows 不需要 Cyder）。
4. 若出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
5. 若遊戲打不開、提示缺少 VCRUNTIME140.dll，請安裝 Microsoft「Visual C++ 可轉散發套件（x64）」。
6. 想用自己的簡中卡圖與牌組：從私人備份儲存庫下載卡圖壓縮檔，把 Assets 資料夾放進遊戲資料夾。
注意：不要把 Mac 上做好的中文版遊戲檔直接複製到 Windows 使用（裡面是蘋方字型，授權只限 Apple 裝置）；
在 Windows 上用 .bat 重新產生即可。Windows 版尚未在實際的 Windows 電腦上測試過，有問題請把視窗訊息告訴我。

■ 自動更新的細節
- 中文化會改動 6 個遊戲檔案；這 6 個檔案的官方原檔保存在 _zh_tools\pristine，每次更新都用它重新產生中文版。
- 驗證沒通過時，工具會改放官方原檔（英文版），遊戲仍可正常遊玩，不會壞掉；請把終端機視窗的訊息告訴我。
- 新版本通常會加入新卡。新卡的對戰文字一開始會是英文，
  工具會把清單存成 _zh_tools\new_strings_<版本>.json，請我補翻後再雙擊一次啟動檔就會套用。
- 更新前被替換的舊檔會備份在 _zh_tools\backup（只保留最近一次）；確認新版沒問題後可以刪除。

■ 1.19.0 這次更新做了什麼
- 遊戲從 1.18.8 更新到官方 1.19.0（12 個檔案，167.5 MB）。
- 1.19.0 新增的 EX13 等新卡，已補翻 176 句對戰文字（選擇提示、效果名稱、效果說明）。
- 用 1.19.0 的原始碼重新檢查過：既有的一萬三千多句翻譯，在新版本中都沒有被規則程式拿去比對，仍然安全。
- 修正一個舊問題：有 34 句「組裝（Assembly）」條件文字之前被翻成中文，但規則程式會拿它們搜尋卡片文字，
  翻了可能影響部分卡片判斷。這 34 句已恢復英文。
- 1.19.0 的卡圖載入方式：你的簡中卡圖（Assets\Textures\Card\卡號.webp）仍優先使用；
  缺圖的新卡，遊戲會自動從官方新來源下載圖片（英文／日文卡圖）。

■ 已翻成中文的部分
- 選單、設定、牌組編輯、對戰畫面等所有介面。
- 對戰文字約 13,800 句：選擇提示（「請選擇 1 隻要消滅的數碼寶貝。」）、效果名稱、效果說明、對戰紀錄、指令按鈕。
- 時機標籤與關鍵字：[登場時] [進化時] [攻擊時] [消滅時] [雙方的回合] [每回合1次]；《阻擋者》《速攻》《貫通》…
- 效果文字裡提到的卡名與特徵用「」框起來。中文名稱是從你的簡體官方卡圖辨識後轉成繁體，
  可能與台灣官方譯名略有出入；完整對照在「名詞對照表.txt」，想改哪個名稱告訴我即可。

■ 還是英文或日文的部分
- 卡片名稱、卡片詳細資料面板裡的效果文字：來自卡片資料庫，只有英文或日文（設定裡的「語言」只決定這個）。
- Bot／Player 的名稱、程式除錯訊息、網路相關字串。
- 組合技（數碼合體 DigiXros、組裝 Assembly、合步進化）的條件描述，以及少數由程式拼湊的句子：
  規則程式會拿這些英文搜尋卡片文字，翻了會讓組合技失靈，所以刻意保留英文。

■ 為什麼可以安全地翻對戰文字
遊戲的規則程式會「用英文字樣判斷效果」（例如看到 [On Play] 才知道是登場時效果）。
所以翻譯時，規則程式裡用來比對的那些字也一起換成同樣的中文，並逐句檢查標籤、關鍵字、數字、格式符號，
以及規則判斷結果在英文版與中文版是否一致。

■ 字型
繁體字使用你電腦內建的系統字型：macOS 用蘋方-繁（PingFang TC），Windows 用微軟正黑體。
建置時才從本機抽出內嵌到遊戲檔，只供自己使用，請不要散布做好的中文版遊戲檔。

■ 如果遊戲打不開或閃退
1. 在 Game\DCGO_Data\il2cpp_data\Metadata\ 裡，把 global-metadata.dat 改名備用，
   再把 global-metadata.dat.原版 改名為 global-metadata.dat。
   （global-metadata.dat.原版 會隨每次更新自動換成目前版本的官方原檔。這樣做會讓對戰文字回到英文，介面仍是中文。）
2. 若這樣就能開啟，代表問題出在對戰文字的部分，請告訴我。

■ 其他
- _zh_tools 是中文化工具與翻譯表（zh_tw.py：介面翻譯；zh_v2_map.json：對戰文字翻譯）。
- 想刪掉這份中文化遊戲：直接刪除本資料夾。
